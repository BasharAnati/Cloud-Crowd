# Adopt Cloud Crowd UI Architecture v1.0

## Status

Accepted

## Decision

Cloud Crowd officially adopts the UI Architecture v1.0 document as the authoritative reference for all frontend work.

## Consequences

- All future UI work must follow the architecture.
- Shared components must be reused.
- No page may introduce its own design system.
- Design Tokens remain the single source of truth.
- New pages must use one of the approved page families.
- Any architectural deviation requires a new ADR.
